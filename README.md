# 🧠 Policy AI Assistant – Generative AI Policy Analysis System

An AI-powered application designed to analyze policy documents, generate structured insights, and provide context-aware responses using Retrieval-Augmented Generation (RAG).

---

## 🚀 Overview

The Policy AI Assistant is a smart system that helps users understand complex policy documents through:

- 📄 Automated summarization  
- 🧾 Scenario-based draft generation  
- 💬 Context-aware question answering  

The system leverages NLP techniques and modern AI APIs to deliver meaningful and actionable insights from large policy datasets.

---

## ✨ Features

- 🔍 **Policy Document Analysis**
  - Extracts key insights from policy texts

- 🧠 **RAG-based AI System**
  - Combines retrieval and generation for accurate responses

- 💬 **Interactive Q&A**
  - Allows users to ask questions and receive context-aware answers

- 📑 **Summarization**
  - Generates structured summaries of policy documents

- 🧾 **Scenario-based Draft Generation**
  - Produces policy drafts based on different use cases

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **Framework:** Streamlit  
- **AI / NLP:** TF-IDF, NLP techniques, RAG  
- **API:** Gemini API  
- **Frontend:** HTML, CSS, JavaScript  

---

## 🏗️ System Architecture

1. Upload policy document  
2. Preprocess text using NLP techniques  
3. Convert text into vector representation (TF-IDF / embeddings)  
4. Retrieve relevant content  
5. Generate responses using AI model  
6. Display results via Streamlit interface
